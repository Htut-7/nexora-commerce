
# Nexora Commerce

Modern fashion e-commerce platform built with React, Vite, Firebase Authentication, and Cloud Firestore.

## Features

* User Authentication (Login & Registration)
* Product Catalog
* Product Search
* Category Filtering
* Product Detail Pages
* Wishlist Management
* Shopping Cart
* Checkout System
* Order Management
* User Profile Management
* Contact Form
* Responsive Design

## Tech Stack

### Frontend

* React
* React Router
* Vite
* CSS3
* React Icons

### Backend

* Firebase Authentication
* Cloud Firestore

## Installation

```bash
git clone https://github.com/Htut-7/nexora-commerce.git

cd nexora-commerce

npm install

npm run dev
```
